## 一、先想清楚方向

Web 安全方向大致可以分为：

- **漏洞挖掘 / 渗透测试**：偏攻击视角，重视信息收集与利用链
- **代码审计**：偏防御视角，从源码找问题
- **安全开发 / 安全建设**：把安全能力做进产品
- **应急响应 / 溯源**：偏运维与取证

路线本身不重要，**能持续输出**才重要。

## 二、基础阶段（1~2 个月）

### 2.1 网络与协议

- HTTP/HTTPS 报文结构、状态码、Cookie/Session
- DNS、TCP 三次握手、代理与隧道
- 推荐工具：浏览器 F12、Burp Suite、curl

### 2.2 编程基础

```python
# 请求与解析是安全测试的地基
import requests

resp = requests.get("https://example.com", timeout=5)
print(resp.status_code, len(resp.text))
```

至少熟练掌握一门脚本语言（Python）和一门后端语言（PHP / Java / Go 任选）。

## 三、核心漏洞阶段（2~3 个月）

按 OWASP Top 10 为主线，逐个搞懂**原理 → 利用 → 修复**：

| 漏洞 | 关键点 |
| :--- | :--- |
| SQL 注入 | 报错/布尔/时间盲注、WAF 绕过 |
| XSS | 反射/存储/DOM，上下文与编码 |
| SSRF | 协议利用、云元数据、内网探测 |
| 文件上传 | 解析漏洞、竞争条件、内容绕过 |
| 反序列化 | PHP/Java 链构造与利用 |
| 越权 | 水平/垂直越权、IDOR |
| 逻辑漏洞 | 支付、验证码、并发竞争 |

> 每个漏洞都建议在本地靶场复现一遍：DVWA、Pikachu、Vulhub、build-your-own-lab。

## 四、进阶阶段

1. **代码审计**：从 `SQL 拼接`、`文件包含`、`命令执行` 三类 sink 开始反查变量来源
2. **内网渗透**：域环境、Kerberos、横向移动、权限维持
3. **工具与自动化**：写自己的指纹识别、POC 框架、爬虫
4. **CTF / 众测**：用比赛和项目倒逼学习

## 五、避坑建议

- 不要只看视频不动手，**每学一个点就复现一次**
- 不要一上来就堆工具，先理解原理
- 不要在未授权的目标上做任何测试，**这是底线**
- 坚持写笔记，能讲清楚才代表真的懂

## 六、写在最后

安全是长期主义。技术会过时，**学习方法不会**。
